# BROS Commercial Intelligence — MVP

## MVP objective

Make one complete internal intelligence case possible from evidence through learning.

## MVP workflow

1. Create an Evidence item.
2. Identify or create a Signal.
3. Open a Case.
4. Record Diagnosis.
5. Record Decision.
6. Create Action.
7. Record Outcome.
8. Capture Learning.

## MVP screens

### 1. Home / Intelligence Queue
Shows:
- active cases
- unresolved signals
- recent decisions
- recent outcomes

### 2. Evidence
Create, inspect, and link evidence.

### 3. Cases
List and inspect bounded commercial cases.

### 4. Case Workspace
Single workspace containing:
- case question
- evidence
- signals
- diagnosis
- decision
- actions
- outcomes
- learning

### 5. Learning
Searchable collection of validated learnings.

## MVP does not require

- charts as the primary interface;
- external customer accounts;
- public sign-up;
- automated scraping;
- predictive analytics;
- autonomous decisions;
- complex role hierarchies;
- multi-tenant architecture.

## Acceptance criterion

An authorised internal operator can complete and later inspect one end-to-end case without leaving the application or losing provenance.

## Build principle

Build the workflow first. Add analytics and integrations only when they materially improve the workflow.
